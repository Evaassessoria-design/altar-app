# Depois da live — o caderno

**Este arquivo é para escrever DURANTE a apresentação e nas duas horas
seguintes**, não na semana que vem. O que se anota depois é o que se lembra, e
o que se lembra nunca é o que doeu.

Nada aqui vira tarefa sozinho. A triagem é depois, com calma.

---

## Como anotar

Uma linha por coisa, sem organizar. Organizar na hora é o que faz parar de
anotar.

```
[bloco 4] a lista de compras demorou uns 4s para pintar
[pergunta] "e se eu tiver dois casamentos no mesmo dia?"
[cara feia] ninguém entendeu a prateleira "Inspiração"
```

As três etiquetas que importam:

- `[bloco N]` — algo que travou, demorou ou saiu feio num bloco
- `[pergunta]` — o que a plateia perguntou, **com as palavras dela**
- `[cara feia]` — o momento em que você sentiu que não entenderam

## Já sabemos que vai aparecer

Registrado antes para não ocupar espaço mental no dia. Se aparecer, é só
marcar `+1` — a contagem é o dado.

| O que vão perguntar | Contagem | A resposta honesta hoje |
|---|---|---|
| "Ele manda WhatsApp para a cliente?" | | Não. Ele escreve a mensagem; quem envia é você |
| "Dá para duas pessoas usarem a mesma conta?" | | Hoje cada conta é de uma pessoa |
| "Ele lê meu contrato em PDF?" | | Lê, mas é IA e pede revisão. Não demonstrado ao vivo de propósito |
| "Funciona no celular?" | | Sim — e é onde a decoradora mais usa |
| "Quanto custa?" | | O que estiver na landing. Nada de improviso |
| "E se eu já tenho tudo em planilha?" | | Importação existe para leads; evento é cadastro |

## Triagem — só depois de dormir

Quando for olhar isto de novo, a ordem é esta, e não outra:

1. **O que você prometeu e não existe** — é dívida com uma pessoa real, e
   corre antes de qualquer melhoria
2. **O que travou ao vivo** — quem viu, viu
3. **A pergunta que mais se repetiu** — é a lacuna que o produto tem hoje, dita
   por seis pessoas diferentes
4. **O resto**

O resto vai para `docs/ideias-registradas.md`, que é onde ideia sem dono mora.
